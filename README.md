# دوچرخه‌سرا

نمونه‌کار فرانت‌اند یک فروشگاه تخصصی دوچرخه به‌همراه سامانه نمایشی خدمات و تعمیرات است. رابط کاربری فارسی و واکنش‌گراست و بدون فرایند build اجرا می‌شود.

## امکانات

- نمایش و فیلتر محصولات و نمایندگان
- مشاهده سریع محصول و سبد خرید محلی
- فرم تماس و عضویت نمایشی
- ثبت درخواست تعمیر و تولید کد رهگیری
- رهگیری وضعیت، هزینه و توضیحات تعمیر
- پنل نمایشی تعمیرگاه برای تغییر وضعیت درخواست
- پشتیبانی از صفحه‌کلید و نمایش موبایل

## اجرای محلی

در PowerShell و داخل پوشه پروژه اجرا کنید:

```powershell
.\server.ps1
```

سپس نشانی زیر را باز کنید:

```text
http://127.0.0.1:8080/
```

برای انتخاب درگاه دیگر:

```powershell
.\server.ps1 -Port 8090
```

## اجرای تست‌ها

Node.js باید نصب باشد. بار اول:

```powershell
npm install
npx playwright install chromium
```

در یک پنجره PowerShell سرور را اجرا کنید و در پنجره‌ای دیگر تست را بزنید:

```powershell
npm test
```

در صورت استفاده از Chrome نصب‌شده می‌توانید مسیر آن را مشخص کنید:

```powershell
$env:BROWSER_PATH='C:\Program Files\Google\Chrome\Application\chrome.exe'
npm test
```

## نکته مهم درباره نسخه نمایشی

درخواست‌های تعمیر، وضعیت رهگیری و سبد خرید در `localStorage` همان مرورگر ذخیره می‌شوند. فرم تماس و خبرنامه نیز ارسال واقعی به سرور ندارند. بنابراین این نسخه یک نمونه‌کار فرانت‌اند است و برای استفاده عملیاتی به بک‌اند، پایگاه داده و احراز هویت نیاز دارد.

کد رهگیری نمونه برای نمایش قابلیت رهگیری:

```text
BS-DEMO-1405
```
